# Sliding Doors — demo video script

Each numbered line is both the on-screen text (kinetic caption or literal UI
moment) and the voiceover line read over it. Lines marked **[silent]** are
on-screen only — no voiceover.

## 1. Hook
> What if the 84th-minute goal never happened?

## 2. Problem (a)
> We'd have won if that goal hadn't gone in.

## 3. Problem (b)
> Now you can test it.

## 4. Product — the turning point
On-screen adds an explicit label at the 84' marker: "Real match: 91% → 9%"
> Minute 84: one goal swings the match.

## 5. Product — the what-if
> Cancel it. Replay the match.

## 6. Product — the reveal
On-screen label: "Without the goal" next to the big 9% → 92%.
> Without that goal, Dunmore Town's win chance jumps from 9% to 92%.

## 7. AI agent — the question
> Or just ask the AI agent.

## 8. AI agent — thinking **[silent, soft SFX only]**
Real "Thinking…" spinner stays on screen; no voiceover.

## 9. AI agent — the answer
> Same answer, in plain English.

## 10. Closing — wordmark
> Sliding Doors.

## 11. Closing — tagline
> Stop debating the what-if. Simulate it.
